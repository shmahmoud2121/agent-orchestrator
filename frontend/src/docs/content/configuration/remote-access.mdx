---
title: Local-only
description: This build of AO runs entirely on your machine. Remote access is disabled.
---

Remote access is disabled in this build. There is no **Connect Mobile** pairing, no **Remote hosts**, and no `ao remote-host` command. A mobile connection saved by an earlier build is ignored; nothing starts from it.

## What AO never does

- **No network listener beyond loopback.** The daemon binds `127.0.0.1` only. There is no LAN listener (port `3011`), no `cloudflared` tunnel, and no Tailscale serve.
- **No telemetry.** Events stay in the local database. Nothing is sent to PostHog or Sentry, whatever `AO_TELEMETRY_*` or `AO_SENTRY_DSN` say.
- **No auto-update or version checks.** The app never checks a release feed, the desktop version floor, or feature builds. Harness update checks are off and cannot be turned on.
- **No pricing fetch.** Usage costs come from a pricing catalog bundled with the app.
- **No cloud.** AO Cloud sign-in, cloud sessions, and the control plane are off.
- **No link-preview unfurling** and no push notifications.

## What still uses the network

- Agent CLIs (Claude Code, Codex, and others) talk to their own model providers.
- Git, GitHub, and GitLab operations you configure, such as fetching, pushing, and pull request status.
- Pages you open in the built-in browser, and images (such as repository avatars) shown in the app.
